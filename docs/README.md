# NIB documentation

**NIB 1.0.0 · stable** · [Download](https://github.com/MooradXO/NIB-Editor/releases/latest) · [Home](../README.md) · [Ask a question](https://github.com/MooradXO/NIB-Editor/discussions)

Build your first game, explore the examples, then use the reference for a particular tool.
These guides describe the downloadable Editor. No source checkout or public npm SDK is needed.

## Start here

1. [Install and launch](../GETTING_STARTED.md) — Node, the editor ZIP and common startup problems.
2. [Meet the editor](06-GETTING-STARTED.md) — panels, create/save/reopen, Play and exports.
3. [Your first game](FIRST-GAME.md) — build Collect Three from Empty 3D, add rules, win/lose/retry and a local best.
4. [Write game scripts](SCRIPTING.md) — lifecycle, parameters, input, entities, UI and cleanup.
5. [Explore the preset gallery](PRESETS.md) — ten games, six showcases and two empty templates.
