# Get help with NIB

- **How do I…?** Ask a usage question in [Discussions](https://github.com/MooradXO/NIB-Editor/discussions).
- **Something is broken:** use the [bug form](https://github.com/MooradXO/NIB-Editor/issues/new?template=bug_report.yml).
- **A feature would help:** use the [feature form](https://github.com/MooradXO/NIB-Editor/issues/new?template=feature_request.yml).
- **A security issue:** use the private channel in [SECURITY.md](SECURITY.md). Do not post vulnerability details publicly.

Before reporting, check [setup](GETTING_STARTED.md), [known limitations](docs/COMPATIBILITY.md) and [release notes](CHANGELOG.md).
Include the NIB version, OS, browser, GPU/backend, exact steps, expected/actual behavior and a small project
you are allowed to share. Remove credentials, private assets, personal paths and unrelated data from logs.

Public replies are best effort; no paid support plan or response-time commitment is offered here.
Official owner: [Murad Mammadov / MooradXO](https://github.com/MooradXO).
