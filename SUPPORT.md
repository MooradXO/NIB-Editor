# Support NIB

NIB is under active development. The best support channel depends on the kind of request:

- Reproducible bugs belong in the [NIB-Editor issue tracker](https://github.com/MooradXO/NIB-Editor/issues).
- Feature proposals belong in a feature request and should explain the user problem first.
- Usage questions may use GitHub Discussions after that feature is enabled for the repository.
- Security reports must follow [SECURITY.md](SECURITY.md) and must not be posted publicly.

Include the NIB commit or version, operating system, browser version, graphics backend, minimal
reproduction, expected result, actual result, and relevant console output. Remove tokens, personal
paths, private project data, and proprietary assets before attaching logs or projects.
