NIB THIRD-PARTY NOTICES
=======================

Distribution scope: this document retains the broader upstream inventory for
attribution and audit context. The public documentation repository does not
contain engine sources or build dependencies. The editor archive includes the
runtime dependencies and release-preset assets identified below, but excludes
the Blade Showcase models and development-only HDRI fixture. Paths below refer
to the editor archive or upstream inventory, not to files in this documentation
repository. Complete runtime license texts accompany this document in licenses/.

This inventory describes direct dependencies and starter dependencies declared by this
repository. Exact resolved versions are recorded in package-lock.json. Transitive dependency
notices remain available in each installed npm package and in generated dependency inventories.
